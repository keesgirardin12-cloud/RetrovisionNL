# RetrovisionNL

Eigen IPTV-app voor LG webOS-tv's: live zenders (Toonami Aftermath, Snick, NHK World, RetroBlast, iptv-org-lijsten) en lokale series vanaf de pc ("Eigen lijst").

## Installeren
```
ares-package . -o ..
ares-install nl.kees.iptvplayer_<versie>_all.ipk -d tv
```

## Bediening
- Kanaal +/- : volgende/vorige zender of aflevering
- Pauze/Play/Stop, links/rechts ±10 s, FF/REW ±30 s
